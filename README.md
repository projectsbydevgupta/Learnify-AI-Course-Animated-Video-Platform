# Learnify — Multi-Agent AI Course & Animated Video Platform

> An autonomous multi-agent educational platform that transforms any Computer Science topic or textbook syllabus into grounded lecture notes, an independent Gemini 2.5 Flash quality audit, a synchronized 1080p animated video lecture, a 2-round adaptive quiz, and a 24/7 guardrailed AI Tutor.

## Core Features

- **3-Tier Hybrid Knowledge Cascade**: Local ChromaDB textbook vector store (`gemini-embedding-2-preview` 768-d embeddings with topical relevance auditing) → Tavily academic web search → Groq LPU (`openai/gpt-oss-120b`) synthesis with source citations.
- **Cross-Provider LLM-as-a-Judge Gate**: Google Gemini 2.5 Flash audits factual accuracy, grounding, code correctness, and clarity; drafts scoring `< 75%` trigger an automated self-healing revision loop.
- **Synchronized 1080p Animated Video Engine**: `VisualPlannerAgent` maps verified scripts into 8-scene storyboards rendered at 30 FPS across **16 React 19 / Remotion 4.0** visual templates, locked to parallel **Microsoft Edge-TTS** voiceovers via **Mutagen** centisecond timing (`+0.4s` buffer).
- **2-Round Adaptive Misconception Quiz**: 3 Round-1 conceptual MCQs with misconception diagnostics, plus on-demand Round-2 targeted remediation questions generated by `AdaptiveAgent`.
- **24/7 Guardrailed AI Tutor**: Grounded in active lesson notes and ChromaDB chunks, protected by a 4-stage **TypeSafe Jev System One** guardrail cascade (`0ms` regex → `512`-entry LRU cache → `jev-latest` 3-Noul schema → Groq 20B fallback).
- **Dual Modes & Resilient Fallbacks**: Supports Single Topic Studio and Master Textbook Curriculum Course Studio, with automatic `PostgreSQL → SQLite`, `Celery/Redis → FastAPI BackgroundTasks`, and `Edge-TTS → Windows SAPI` fallbacks.

## Quick Start

### Prerequisites
- **Python 3.10+** and **Node.js 20+**
- API keys configured in `backend/.env` (see `backend/.env.example`) and `frontend/.env.local` (see `frontend/.env.example`)

### 1. Backend Setup (`Port 8000`)
```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
# Add your GROQ_API_KEY, GEMINI_API_KEY, TAVILY_API_KEY, TYPESAFE_API_KEY to backend/.env
python ingest_all_10_clean.py
uvicorn main:app --host 127.0.0.1 --port 8000
```

### 2. Video Engine Setup
```bash
cd video-engine
npm install
```

### 3. Frontend Setup (`Port 3000`)
```bash
cd frontend
npm install
copy .env.example .env.local
# Add your Clerk keys and NEXT_PUBLIC_BACKEND_URL=http://localhost:8000
npm run dev
```

*(On Windows, after installing dependencies, you can launch all services at once via `start_platform.bat`.)*
